# Code of Conduct

## Our standard

ORIGIN is built for disagreement without intimidation. Participants are expected to challenge claims with evidence, distinguish criticism from personal attack, disclose relevant conflicts, represent opposing arguments accurately, protect private information, and accept that uncertainty may remain unresolved.

Unacceptable behavior includes harassment, threats, doxxing, discriminatory language, coordinated disruption, knowingly fabricated evidence, and attempts to pressure maintainers into suppressing reproducible findings.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, project events, and public spaces where someone represents ORIGIN.

## Enforcement

Report conduct concerns privately to the repository owner or through GitHub’s reporting tools. Maintainers may edit or remove content, lock discussions, reject contributions, or temporarily or permanently restrict participation.

Enforcement decisions should be documented when doing so does not expose a reporter or create a security risk.
