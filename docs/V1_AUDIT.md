# ORIGIN v1 audit

This document records the v1 release boundary. ORIGIN is considered complete as a verification platform when deterministic report sealing, signed checkpoints, inclusion proofs, hardened build-manifest validation, an accessible offline interface, automated tests, and documented operator procedures are present and passing.

A live implementation audit remains revision-specific and requires pinned artifacts, synchronized nodes, implementation-specific vectors, signed operator evidence, and independent replication.
